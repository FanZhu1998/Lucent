## Context

What problem or force makes a decision necessary now? Cite the relevant blueprint sections,
constraints (platform, licensing, memory, reproducibility) and facts that were verified, with
dates or versions where they matter.

## Decision

What was decided, stated so that someone can check whether the code follows it. Number the
parts when there are several.

## Consequences

What becomes easier or harder: positive and negative effects, obligations created, follow-up
work, and what would cause this decision to be revisited.

## Alternatives considered

Each serious alternative, with the reason it was not chosen.
